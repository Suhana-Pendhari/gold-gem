# Gleam & Grace | Luxury Jewelry E-commerce
---

A sophisticated, fully responsive front-end web application for a high-end jewelry boutique. This project showcases a luxury user interface built with modern web technologies, featuring interactive elements and a seamless shopping experience.



---

### ## Key Features
* **Elegant UI/UX:** Luxury aesthetic utilizing the Cinzel and Montserrat font pairings.
* **Interactive Modals:** Custom-built Shopping Cart and Wishlist sidebars for a modern shopping flow.
* **Dynamic Navigation:** Responsive navigation bar with a hamburger menu for mobile users.
* **Advanced Search:** Full-screen search overlay with popular suggestion tags.
* **Animations:** Custom CSS diamond-shaped preloader and sparkle effects on hero images.
* **Handcrafted Sections:** Dedicated layouts for Collections, Product Categories, and Craftsmanship stories.

---

### ## Tech Stack
* **HTML5:** Semantic markup for structure.
* **CSS3:** Custom properties (variables), Flexbox, Grid, and Keyframe animations.
* **JavaScript (ES6):** DOM manipulation, event handling, and UI logic.
* **Font Awesome:** Vector icons for social media and UI elements.
